# EasyTicket

Portal untuk menjelajahi destinasi wisata, melihat informasi merchant, dan memesan tiket.

## Buka website

- GitHub Pages: https://easyticket-hash.github.io/easyticket.id/
- Website produksi: https://easyticket-explore-book.khairani0894.chatgpt.site/

GitHub Pages diarahkan ke versi produksi EasyTicket **release 117**, termasuk halaman Affiliate dan verifikasi OTP email.

## Catatan hosting

Halaman GitHub Pages meneruskan pengunjung ke website produksi. Fitur yang memerlukan backend—seperti pengiriman OTP, checkout, portal Affiliate, dashboard merchant, dan CMS—tetap berjalan di hosting aplikasi utama agar fungsinya tetap aktif.
