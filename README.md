# EasyTicket

Portal EasyTicket untuk menjelajahi destinasi wisata, melihat informasi merchant, dan memesan tiket.

## Buka website

- GitHub Pages: https://easyticket-hash.github.io/easyticket.id/
- Website utama: https://easyticket-explore-book.khairani0894.chatgpt.site/

GitHub Pages meneruskan pengunjung ke website utama agar halaman destinasi, merchant, checkout, dan fitur yang memakai layanan backend selalu menggunakan versi produksi terbaru. Rilis website versi 100 menghapus catatan katalog lama dari halaman destinasi, memperbarui keterangan tiket, dan menyederhanakan hero Promo menjadi satu foto ber-gradient dengan teks diskon up to 50%.

## Catatan

Source aplikasi lengkap dan layanan backend dijalankan pada website utama EasyTicket. Repository ini menyediakan halaman masuk GitHub Pages ke aplikasi tersebut.
