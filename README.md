# EasyTicket

Website EasyTicket: destinasi wisata, promo, pemesanan tiket, halaman Affiliate, dan verifikasi OTP.

## Buka website

- GitHub Pages: https://easyticket-hash.github.io/easyticket.id/
- Aplikasi produksi: https://easyticket-explore-book.khairani0894.chatgpt.site/

Halaman GitHub Pages menampilkan aplikasi produksi di dalam frame sehingga alamat browser tetap menggunakan domain GitHub Pages. Proses OTP, checkout, dashboard, dan layanan backend tetap dijalankan oleh aplikasi produksi EasyTicket.
